UIT RGPV College Website — Student Major Project


TECHNOLOGIES
- HTML5 (semantic elements, metadata, accessible labels and tables)
- CSS3 (responsive layout, simple styling and hover states)
-  little bit ONLY Vanilla JavaScript (mobile navigation and demo form feedback)

IMPORTANT PROJECT NOTES
- The website is a static front-end project. Registration, feedback and contact forms show a demo success message; they do not send or save data.
- Timetable and marks are sample data. Replace them with approved/current information before submission.
- Faculty details are kept general to avoid publishing invented staff names.
- The image URLs supplied by the student are used directly. An internet connection is required for remote images and Google Fonts.
- Some Google thumbnail image links may expire or stop loading. If that happens, replace the image URL in the relevant HTML file with a stable direct image link.
- This is an academic student project, not an official website of UIT or RGPV.

PAGES
Home, About, Departments, Courses, Faculty, Student Life & Achievements,
Weekly Timetable, Marks Record, Registration, Feedback and Contact.
